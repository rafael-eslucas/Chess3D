# Chess3D

Este projeto que se encontra em tua frente é nada mais que uma tentativa de programar uma variante de xadrez tridimensional criada por mim mesmo. O jogo pode ser jogado de duas formas:
1. Offline, com um aplicativo desktop com a biblioteca raylib (pretendo implementar a versão online do aplicativo desktop)
2. Online, num site que consulta um servidor c++ que usa a biblioteca crow
